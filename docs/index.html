Talashly

Your own search engine. Own crawler, own index, cited AI answers. Written in Python, no third-party search or AI APIs.

View on GitHubQuick start

Own crawler

Respects robots.txt and crawl-delay, uses sitemaps, ETag, dedupe and adaptive recrawl.

Own index

SQLite FTS5 with BM25, freshness and domain diversity. Trigram index for Chinese, Japanese, Korean and Thai.

Cited answers (RAG)

Answers built only from indexed pages, with sources. Optional local LLM with grounding check.

Code search

Index your own folders and search functions, classes and identifiers.

Self-healing

Crawler restarts, integrity checks, rotating backups and automatic restore.

Multi-user

API keys, roles, rate limits and background tasks.

Free models and API

Five free MUS 7.01 profiles (balanced, flash, deep, code, polyglot) and an OpenAI-compatible API with free self-serve keys. Answers carry citations, and when the sources do not contain an answer Talashly says so.

Quick start

Windows: run INSTALL.bat once, then START.bat and open http://127.0.0.1:8000.

git clone https://github.com/musman550/talashly
cd talashly
pip install -r requirements.txt
python -m engine serve

Good to know

  • This page is only the project site. To put the chat app online for everyone, follow HOSTING.md.
  • It does not scrape Google, Bing or DuckDuckGo. You choose the sources in seeds.toml.
  • JavaScript-rendered sites and vector search are not included yet.
