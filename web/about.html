About Talashly

A free answer engine that shows its sources. It owns its crawler, its index and its answers.

Open the chat

How it works

Talashly's crawler visits the sites its owner chooses (respecting robots.txt and crawl delays), stores the text in its own index, and refreshes it on a schedule. When you ask a question it searches that index, picks the sentences that answer it, and writes the answer. Sources are shown only when you ask for them or use the Deep model. If the index does not contain the answer, it tries live research on configured sources; if that fails, it tells you plainly.

Frequently asked questions

What is Talashly?

Talashly is a free, open-source answer engine. It has its own web crawler and its own search index, and it answers questions in a chat interface.

Is Talashly free?

Yes. The chat and all MUS 7.01 models are free. There are fair-use rate limits and a daily quota per key so one user cannot overload the server; the server owner can raise or remove them.

Does it use Google, Bing, ChatGPT or other third-party APIs?

No. Talashly crawls the sources its owner configures, builds its own index, and answers from that index. It does not call third-party search or AI APIs and it does not scrape Google, Bing or DuckDuckGo.

Can the answers be wrong?

Yes, any AI can be wrong. Talashly writes answers only from text found in its indexed sources. If it does not have the answer it says so instead of guessing. Choose the Deep model, or ask for sources, to see the pages behind an answer.

What are the MUS 7.01 models?

They are free answer-engine profiles that work differently on the same index: Balanced, Flash (fastest, index only), Deep (multi-step research), Code (searches code you indexed) and Polyglot (more live research for non-English questions). They are not separate trained neural networks. If the owner connects a local LLM, it helps write the answer and every sentence is still checked against the sources.

Which languages are supported?

Search and answers are tested in English, Urdu, Arabic, Hindi, Russian, Chinese, Japanese, Korean, Thai, French, German and Spanish. Answers can only be as good as the sources the crawler has indexed in that language.

How do I get an API key?

Open the chat, click API key, then Create a new free key. You can also call POST /api/keys. The key works with the OpenAI-compatible endpoint, so tools such as n8n, Zapier-style webhooks and OpenAI SDKs can use Talashly.

Is Talashly open source?

Yes. The code is on GitHub at github.com/musman550/talashly under the MIT license, and you can run your own copy on Windows, Linux or Docker.

Talashly is open source (MIT). It is an AI and can make mistakes: double-check anything important.
