Talashly API

Use Talashly from your own apps and automations. It speaks the OpenAI chat-completions format, so most tools work by changing the base URL.

1. Get a free key

Click API key in the chat, or call:

curl -X POST {{SITE_URL}}/api/keys -H "Content-Type: application/json" -d '{"label":"my-app"}'

The key (starts with ss_) is shown once. Keep it secret.

2. Call the chat endpoint

Base URL: {{SITE_URL}}/v1. Send the key as Authorization: Bearer KEY (or X-Api-Key).

curl

curl {{SITE_URL}}/v1/chat/completions \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"mus-7.01","messages":[{"role":"user","content":"What is a polite crawler?"}]}'

Python (OpenAI SDK)

from openai import OpenAI

client = OpenAI(base_url="{{SITE_URL}}/v1", api_key="YOUR_KEY")
r = client.chat.completions.create(
    model="mus-7.01",
    messages=[{"role": "user", "content": "What is a polite crawler?"}],
)
print(r.choices[0].message.content)

JavaScript

const r = await fetch("{{SITE_URL}}/v1/chat/completions", {
  method: "POST",
  headers: { "Authorization": "Bearer YOUR_KEY", "Content-Type": "application/json" },
  body: JSON.stringify({ model: "mus-7.01", messages: [{ role: "user", content: "What is a polite crawler?" }] }),
});
console.log((await r.json()).choices[0].message.content);

Add "stream": true for server-sent events. Any no-code tool that accepts a custom OpenAI base URL (n8n, Make, Flowise and others) can use the same URL and key.

Endpoints

MethodPathWhat it does
GET/v1/modelsList the free models
POST/v1/chat/completionsCited answer; OpenAI format; response has a talashly.sources field
GET/api/search?q=Plain search results with snippets
GET/api/code?q=Search code indexed by the server owner
POST/api/chatChat with saved conversations (server-sent events)
POST/api/keysCreate a free API key
GET/api/meYour key's usage today and limits
GET/api/healthServer and index status

Limits and errors

Each key has a per-minute rate limit and a daily quota so that one user cannot overload the server. Errors use the OpenAI shape: {"error":{"message":"...","type":"...","code":"..."}}. Status 401 bad or missing key, 404 unknown model, 429 rate limit or quota, 503 server busy (retry shortly).

Token counts in usage are approximate word counts. A Sources: list is appended only for mus-7.01-deep or when the question asks for sources.

Talashly is open source (MIT). Answers can be wrong: check the cited sources.
